# 🤖 دستیار — چت هوش مصنوعی فارسی، رایگان و متن‌باز

یک دستیار گفتگوی کامل با رابط **فارسی و راست‌به‌چپ** که به سرویس‌های هوش مصنوعی وصل می‌شود.
بدون ثبت‌نام، بدون سرور خارجی، بدون وابستگی npm برای اجرا — فقط یک فایل `node server.mjs`.

> **رایگان چطور؟** با یک ایمیل، از **Google AI Studio** یا **Groq** یا **OpenRouter** یک کلید API رایگان می‌گیری
> (کمتر از ۲ دقیقه) و در برنامه وارد می‌کنی. تمام. کلید فقط داخل مرورگر خودت می‌ماند.

---

## 🚀 اجرای سریع

```bash
cd assistant
npm start          # یا: node server.mjs
# سپس در مرورگر باز کن: http://localhost:3000
```

هیچ `npm install` برای **اجرای برنامه** لازم نیست (صفر وابستگی). فقط اگر خواستی آزمون‌های رابط را اجرا کنی:

```bash
npm install        # فقط برای نصب jsdom (آزمون‌ها)
npm run test:all   # آزمون لایهٔ API + آزمون رابط کاربری
```

### اولین استفاده

1. برنامه باز می‌شود و پنجرهٔ **تنظیمات** خودش بالا می‌آید.
2. یکی از سرویس‌های **رایگان** را انتخاب کن (Gemini / Groq / OpenRouter).
3. روی «دریافت کلید از سایت سرویس» بزن، با ایمیلت وارد شو و کلید را کپی کن.
4. کلید را در کادر **کلید API** بچسبان → دکمهٔ **آزمون اتصال** → بعد **ذخیره و بستن**.
5. حرف بزن! 🙂

اگر فعلاً کلید نداری، **«حالت نمایشی»** را بزن تا محیط برنامه را بدون اینترنت بگردی
(پاسخ‌ها از پیش نوشته‌شده‌اند و واقعی نیستند).

## 🔑 گرفتن کلید رایگان (فقط با ایمیل)

| سرویس | لایهٔ رایگان | آدرس گرفتن کلید |
| --- | --- | --- |
| **Google Gemini** | چند صد درخواست در روز، رایگان | <https://aistudio.google.com/app/apikey> |
| **Groq** | رایگان و بسیار سریع (Llama 3.3 70B و…) | <https://console.groq.com/keys> |
| **OpenRouter** | مدل‌هایی با پسوند `:free` کاملاً رایگان | <https://openrouter.ai/settings/keys> |
| **OpenAI** | پولی (نیاز به اعتبار) | <https://platform.openai.com/api-keys> |

هر سه سرویس اول، کلید را به محض ورود با ایمیل (یا حساب گوگل/گیت‌هاب) نشان می‌دهند.

**نکتهٔ مهم و صادقانه:** این برنامه عمداً هیچ حساب کاربری به‌صورت خودکار نمی‌سازد و ایمیل‌های یک‌بارمصرف
تولید نمی‌کند. ساخت خودکار حساب‌های متعدد برای دور زدن محدودیت‌ها، خلاف شرایط استفادهٔ همهٔ این سرویس‌هاست
و باعث بسته شدن IP/حساب می‌شود. راه درست و پایدارِ «رایگان بودن» همان است که در بالا نوشته شد:
یک کلید رایگان رسمی از هر سرویس — و برنامه هم **همزمان چند کلید را نگه می‌دارد** تا وقتی سهمیهٔ یکی تمام شد،
با یک کلیک از منوی «سویچ سریع سرویس» (پایین نوار کناری) به دیگری بپری.

## ✨ امکانات

- 💬 **گفتگوی جریان‌دار** (نمایش تدریجی پاسخ، مثل ChatGPT) + دکمهٔ توقف
- 🗂 **چند گفتگوی همزمان** با گروه‌بندی زمانی (امروز/دیروز/…)، تغییر نام، حذف و **جستجو** در متن همهٔ گفتگوها
- 🧠 **حافظهٔ قابل تنظیم** (کل گفتگو / ۲۰ پیام / ۸ پیام / بدون حافظه) برای کنترل هزینه و سرعت
- 🎭 **شخصیت‌های آماده**: دستیار عمومی، برنامه‌نویس، مترجم، ویراستار فارسی، مشاور کسب‌وکار، معلم + System Prompt دلخواه
- 🌐 **قانون «همیشه فارسی بده»** با یک کلیک
- 🖼 **پیوست تصویر** (کشیدن‌ورهاکردن، Paste یا دکمهٔ گیره) برای مدل‌های بینا
- 📝 **رندر مارک‌داون کامل**: عنوان، فهرست تودرتو، جدول، نقل‌قول، لینک و **بلوک کد با رنگ‌آمیزی و دکمهٔ کپی**
- ♻️ **پاسخ دوباره / ویرایش پیام** (بازگشت به هر نقطه از گفتگو)
- 📤 **خروجی**: Markdown برای یک گفتگو، JSON برای پشتیبان کامل + **بازگردانی** از فایل
- 🌙 **پوستهٔ تیره/روشن**، طراحی واکنش‌گرا (موبایل هم کامل کار می‌کند)
- 🔌 **سازگار با هر سرویس OpenAI-like**: LM Studio، Ollama، vLLM، یا هر پروکسی شخصی (سرویس دلخواه + آدرس پایه)
- ⚙️ **آزمون اتصال** و **بروزرسانی فهرست مدل‌ها** از خود سرویس
- 🛡 **خطاهای فارسی و قابل‌فهم** برای ۴۰۱/۴۲۹/۴۰۴/خطای شبکه، با راهنمای رفع مشکل

## 🏗 ساختار پروژه

```
assistant/
├─ server.mjs          # سرور ایستای صفر-وابستگی + پروکسی اختیاری /api/chat
├─ env.mjs             # خواندن .env بدون کتابخانهٔ خارجی
├─ package.json        # فقط اسکریپت‌ها (jsdom تنها برای آزمون‌ها)
├─ .env.example        # الگوی کلیدهای سمت سرور (اختیاری)
├─ public/
│  ├─ index.html       # ساختار صفحه (فارسی، dir=rtl)
│  ├─ styles.css       # پوستهٔ تیره/روشن، واکنش‌گرا
│  └─ js/
│     ├─ app.js        # منطق اصلی: گفتگوها، ارسال، تنظیمات، رویدادها
│     ├─ providers.js  # کاتالوگ سرویس‌ها + کلاینت OpenAI-compatible (جریان‌دار)
│     ├─ storage.js    # localStorage، پشتیبان‌گیری، خروجی Markdown
│     ├─ markdown.js   # رندر مارک‌داون امن (escape کامل) + رنگ‌آمیزی کد
│     └─ ui.js         # المان‌ها، مودال، تست، رندر پیام‌ها
└─ tests/
   ├─ api.test.mjs     # ۲۳ آزمون لایهٔ ارتباط (SSE، خطاها، لغو، هدرها)
   └─ ui.test.mjs      # ۲۵ آزمون رابط کاربری با jsdom
```

### دو حالت ارتباط

| حالت | چه‌طور کار می‌کند | کی استفاده کنی |
| --- | --- | --- |
| **مستقیم از مرورگر** (پیش‌فرض) | مرورگر با کلیدِ ذخیره‌شده در `localStorage` مستقیماً به سرویس وصل می‌شود | استفادهٔ شخصی روی کامپیوتر خودت |
| **پروکسی سرور** | درخواست به `/api/chat` روی همین سرور می‌رود و سرور با کلیدِ داخل `.env` سرویس را صدا می‌زند | وقتی کلید را در مرورگر نمی‌خواهی، یا شبکهٔ مرورگر بسته است |

برای حالت پروکسی:

```bash
cp .env.example .env      # کلیدها را وارد کن
npm start                 # حالا در تنظیمات: «از طریق پروکسی سرور»
```

## 🔒 امنیت

- کلید API **فقط** در `localStorage` همان مرورگر ذخیره می‌شود و به هیچ سرور دیگری نمی‌رود (در حالت پیش‌فرض).
- همهٔ خروجی‌های مدل قبل از نمایش **escape** می‌شوند؛ HTML/اسکریپت خام هرگز اجرا نمی‌شود (XSS-safe).
- لینک‌ها با `rel="noopener noreferrer"` و فقط با پروتکل‌های مجاز باز می‌شوند.
- اگر روی کامپیوتر مشترک استفاده می‌کنی، در پایان از «تنظیمات ← داده‌ها ← حذف کلید API» استفاده کن.
- ⚠️ هرگز کلید را در نسخهٔ عمومی/دیپلویشده برای دیگران قرار نده؛ آن نسخه باید حالت پروکسی با کلید سمت سرور داشته باشد
  و ترجیحاً پشت احراز هویت باشد.

## 🌍 دیپلوی

چون برنامه یک سایت ایستا + یک سرور خیلی کوچک است، همه‌جا بالا می‌آید:

```bash
# روی سرور خودت
PORT=8080 npm start

# یا با Docker (اختیاری)
docker run -p 8080:3000 -v $(pwd)/.env:/app/.env node:22-alpine sh -c "cd /app && node server.mjs"
```

یا کل پوشهٔ `public/` را روی هر هاست ایستا (GitHub Pages، Netlify، Cloudflare Pages) بگذار —
در این حالت فقط «مستقیم از مرورگر» کار می‌کند.
