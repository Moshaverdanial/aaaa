# نصب دال روی ویندوز، از صفر (فقط یک فایل)

> هر دستور را در CMD بچسبانید و اینتر (Enter) بزنید. هر بار فقط یک دستور.
> CMD را با کلید ویندوز، نوشتن `cmd` و اینتر باز کنید.

## ۰) آیا نود (Node) نصب است؟

```
node -v
```

باید چیزی مثل `v24.19.0` ببینید (هر عدد ۲۲.۱۳ یا بالاتر درست است).
اگر نوشت `not recognized`: از https://nodejs.org نسخه‌ی LTS را نصب کنید (Next، Next، Finish)، **همه‌ی CMDها را ببندید** و یک CMD تازه باز کنید.

## ۱) پاک‌کردن نسخه‌های قبلی (اختیاری، همه‌ی داده‌ی قبلی پاک می‌شود)

```
taskkill /F /IM node.exe
```

```
for /d %d in ("%USERPROFILE%\Downloads\aaaa*" "%USERPROFILE%\Desktop\aaaa*" "%USERPROFILE%\Documents\aaaa*" "%OneDrive%\Desktop\aaaa*" "%OneDrive%\Documents\aaaa*" "C:\aaaa*" "C:\Dal") do rd /s /q "%d"
```

```
del /q "%USERPROFILE%\Downloads\aaaa*.zip"
```

## ۲) ساخت پوشه

```
mkdir C:\Dal
```

```
cd /d C:\Dal
```

## ۳) دانلود تک‌فایل

```
curl -fL -o dal.js https://github.com/Moshaverdanial/aaaa/raw/arena/01a0f735-aaaa/release/dal.js
```

بررسی: `dir dal.js` — اندازه باید حدود ۳ میلیون بایت (۳ مگابایت) باشد. اگر چند هزار بایت بود یا خطا داد، دانلود خراب است؛ روش جایگزین:

1. این آدرس را در مرورگر بزنید: https://github.com/Moshaverdanial/aaaa/archive/refs/heads/arena/01a0f735-aaaa.zip
2. زیپ را اکسترکت (Extract) کنید.
3. فایل `release\dal.js` را کپی کنید داخل `C:\Dal`.

## ۴) ساخت مدیر (فقط بار اول)

```
node dal.js admin 09123456789 Admin Dal12345678
```

کد بازیابی که چاپ می‌شود را جایی بنویسید (فقط یک بار نمایش داده می‌شود).

## ۵) روشن‌کردن سرور

```
node dal.js
```

باید ببینید: `Dal is running on port 3000 ...`
پنجره را باز نگه دارید و داخلش کلیک نکنید (کلیک، برنامه را موقتاً متوقف می‌کند؛ اگر شد، یک بار Enter بزنید).
اگر پنجره‌ی فایروال (Firewall) آمد: Allow access یا Cancel، هر دو برای `localhost` درست است.

## ۶) باز کردن سایت

مرورگر خودش باز می‌شود. اگر نشد: `http://localhost:3000`
آدرس باید با **http** شروع شود، نه https.
ورود با کیبورد انگلیسی: شماره `09123456789`، رمز `Dal12345678`.

## ۷) اگر در مرورگر خطا آمد

در یک CMD دوم بزنید:

```
curl http://localhost:3000/api/setup/status
```

- جواب `{"needsSetup":false}` یعنی سرور سالم است؛ مشکل از مرورگر است (https، افزونه یا وی‌پی‌ان). آدرس `http://127.0.0.1:3000` را امتحان کنید.
- خطا یعنی سرور روشن نیست؛ به مرحله‌ی ۵ برگردید.

## ۸) توکن تلگرام یا بله

`http://localhost:3000/#/admin/settings` ← پایین بروید ← کادر «ربات تلگرام» (یا «ربات بله») ← توکن ← ذخیره. تلگرام در ایران وی‌پی‌ان لازم دارد.

## ۹) روزهای بعد

روشن‌کردن:
```
cd /d C:\Dal
```
```
node dal.js
```
خاموش‌کردن: داخل پنجره‌ی سرور `Ctrl+C`.
به‌روزرسانی: سرور را خاموش کنید، دستور مرحله‌ی ۳ را دوباره بزنید (داده‌ها در `C:\Dal\data` می‌مانند).
پشتیبان: `node dal.js backup` و بعد پوشه‌ی `C:\Dal\data` را جای امن کپی کنید.
رمز فراموش شد: `node dal.js reset-password 09123456789 NewPass12345`

## اختیاری برای لپ‌تاپ همیشه‌روشن

```
powercfg /change standby-timeout-ac 0
```

و برای اینکه کلیک داخل CMD سرور را متوقف نکند (فقط برای CMDهای جدید):

```
reg add HKCU\Console /v QuickEdit /t REG_DWORD /d 0 /f
```
