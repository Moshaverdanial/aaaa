# اپ اندروید دال

اپ اندروید دال یک برنامه‌ی واقعی (فایل APK) است که سایت دالِ خودِ شما را تمام‌صفحه باز می‌کند و چیزهایی را اضافه می‌کند که مرورگر ندارد:

- اعلان‌های گوشی برای پیگیری‌ها، پیام‌ها و گزارش‌ها، حتی وقتی اپ بسته است. این اعلان‌ها به سرویس‌های گوگل نیاز ندارند، پس در ایران هم کار می‌کنند.
- انتخاب عکس برای آگهی، موقعیت مکانی برای نقشه، ذخیره‌ی فایل‌ها (کد بازیابی، فایل اکسل، QR) در پوشه‌ی Downloads.
- اشتراک‌گذاری با همه‌ی برنامه‌های گوشی، تماس مستقیم، واتساپ، تلگرام و بله.
- صفحه‌ی خطای فارسی وقتی اینترنت یا سرور قطع است.
- آدرس سرور را فقط یک بار می‌پرسد (یا می‌توانید آدرس را داخل خود APK بگذارید).

کد اپ در پوشه‌ی `android/` است. هیچ کتابخانه‌ی بیرونی ندارد و حجم APK حدود ۱۷۰ کیلوبایت است.

## راه ۱: دانلود APK آماده

فایل آماده همیشه داخل خود مخزن است: `release/dal.apk`. همچنین در برگه‌ی Releases گیت‌هاب با نام `android-latest`.

آدرس مستقیم:

```
https://github.com/Moshaverdanial/aaaa/releases/download/android-latest/dal.apk
```

این APK آدرس سرور را در اولین اجرا از کاربر می‌پرسد. برای مشتری‌ها بهتر است APK ای بسازید که آدرس سایت شما داخلش باشد (راه ۲).

## راه ۲: ساخت APK با آدرس سایت خودتان (رایگان، با گیت‌هاب)

بدون نصب هیچ چیز روی کامپیوتر:

1. در گیت‌هاب مخزن را باز کنید و برگه‌ی **Actions** را بزنید.
2. از ستون چپ **Build Android APK** را انتخاب کنید.
3. دکمه‌ی **Run workflow** را بزنید. در کادر آدرس، سایت خودتان را بنویسید، مثلاً `https://dal.example.ir`.
4. حدود سه دقیقه صبر کنید. بعد از پایان، APK در Releases (نام `android-latest`) و در `release/dal.apk` قرار می‌گیرد.

اگر برگه‌ی Actions غیرفعال بود، در Settings ← Actions ← General گزینه‌ی Allow all actions را روشن کنید.

آدرس را برای همیشه ثابت کنید (اختیاری): Settings ← Secrets and variables ← Actions ← Variables ← New repository variable. نام `DAL_SERVER_URL` و مقدار آدرس سایت.

## نصب روی گوشی اندروید

1. فایل `dal.apk` را روی گوشی دانلود کنید (یا از سایت خودتان: `https://دامنه/#/install` که دکمه‌ی دانلود دارد).
2. روی فایل بزنید. اگر گوشی گفت «نصب از منابع ناشناس»، اجازه را برای همان برنامه (مرورگر یا مدیر فایل) روشن کنید.
3. Install را بزنید. اگر Play Protect هشدار داد، Install anyway را بزنید. هشدار برای این است که اپ از فروشگاه نیست.
4. اپ را باز کنید و آدرس سایت را بدهید (اگر داخل APK نیست).
5. وارد حساب شوید. اجازه‌ی اعلان را بدهید.

## گذاشتن APK روی سرور خودتان

سرور دال می‌تواند APK را خودش دانلود بدهد:

```bash
scp release/dal.apk root@IP-SERVER:/opt/dal/data/dal.apk
```

بعد در `https://دامنه/#/install` دکمه‌ی «دانلود اپ اندروید» ظاهر می‌شود و آدرس `https://دامنه/dal.apk` کار می‌کند. اسکریپت `deploy/install.sh` هم اگر `dal.apk` را کنار `dal.js` ببیند، خودش این کار را می‌کند.

## اعلان‌ها چطور کار می‌کنند

- اپ هر ۱۵ دقیقه (کمترین زمانی که اندروید اجازه می‌دهد) سرور خودتان را می‌پرسد و اعلان‌های تازه را به‌صورت اعلان گوشی نشان می‌دهد.
- یادآور پیگیری هر روز ساعت ۸ صبح تهران و گزارش هفتگی (برای مدیر) از همین راه می‌آید.
- اگر گوشی شما شیائومی، سامسونگ یا هوآوی است، در تنظیمات گوشی برای «دال» محدودیت باتری را بردارید. در غیر این صورت اعلان‌ها دیر می‌رسند.

## امضای برنامه و به‌روزرسانی

APK با کلید `android/dal-release.p12` امضا می‌شود (رمز: `dalandroid`، نام: `dal`). این کلید داخل مخزن است تا هر نسخه‌ی تازه روی نسخه‌ی قبلی نصب شود. چون مخزن عمومی است، این کلید راز نیست. اگر خواستید برنامه را در Google Play یا بازار بگذارید، کلید جدید و خصوصی بسازید.

## ساخت روی کامپیوتر خودتان (برای برنامه‌نویس‌ها)

نیاز: JDK 17 و Android SDK (با Android Studio) و Gradle 8.9.

```bash
cd android
gradle assembleRelease -PdalServer=https://dal.example.ir
```

فایل خروجی: `android/app/build/outputs/apk/release/app-release.apk`

## محدودیت‌های صادقانه

- این برنامه سایت را در WebView باز می‌کند؛ پس بدون اینترنت فقط صفحه‌ی خطا و بخش‌هایی که سرویس‌ورکر ذخیره کرده نشان داده می‌شود.
- اعلان فوری (پوش) ندارد، چون پوش واقعی به سرویس‌های خارج از ایران نیاز دارد. به‌جایش هر ۱۵ دقیقه بررسی می‌کند.
- اپ به‌صورت پیش‌فرض آدرس‌های http را هم می‌پذیرد (برای سرور آزمایشی). برای کاربران واقعی از https استفاده کنید.
