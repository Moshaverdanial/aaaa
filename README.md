# دال — پلتفرم هوشمند املاک 🏡

پلتفرم فارسی (راست‌به‌چپ) آگهی ملک؛ بدون وابستگی npm و بدون مرحله‌ی build. **پایگاه‌داده در ابتدا کاملاً خالی است** — هیچ داده‌ی نمایشی، حساب آزمایشی یا آمار ساختگی وجود ندارد.

## راه‌اندازی

```bash
# نیازمند Node.js نسخه‌ی ۲۲.۱۳ یا بالاتر
npm start            # http://localhost:3000
```

در اولین اجرا، کد راه‌اندازی در ترمینال چاپ می‌شود (و در `data/.setup-token` است). یکی از این راه‌ها را بروید:

1. مرورگر: `http://localhost:3000/#/setup` ← کد راه‌اندازی + نام، موبایل و رمز مدیر
2. ترمینال: `npm run admin -- 09123456789 "نام مدیر"` (رمز پرسیده می‌شود)
3. یا با متغیرهای `DAL_ADMIN_PHONE`، `DAL_ADMIN_PASSWORD` (و اختیاری `DAL_ADMIN_NAME`) هنگام اجرا.

سپس از پنل مدیریت (`#/admin`) آگهی‌ها، مشاوران، مجله و گزارش‌ها را مدیریت کنید.

## تمرکز ویژه: بندر کنگان و شیراز 📞

- شماره‌های مشاوره: **۰۹۲۰۶۶۹۶۰۹۲** و **۰۹۲۰۲۲۹۰۹۳۰** (از پنل مدیریت ← «تنظیمات» قابل تغییرند؛ واتساپ، تلگرام، اینستاگرام، ایمیل و نشانی هم همان‌جا).
- بندر کنگان (۳۸ محله و شهرک بر پایه‌ی فهرست شهرداری کنگان) و شیراز همیشه اول فهرست شهرها هستند؛ صفحه‌ی `#/consult`، دکمه‌ی شناور «مشاوره»، هدر و فوتر همه‌جا شماره‌ها را نشان می‌دهند. درخواست‌های تماس در پنل مدیریت ← «پیام‌های تماس» ثبت می‌شود.
- **صداقت داده:** برای محله‌های کنگان مختصات و قیمت مرجع تأییدشده‌ای نداریم و عددی ساخته نشده است؛ نقشه روی مرکز شهر می‌ایستد و تحلیل بازار فقط از آگهی‌های واقعی ثبت‌شده محاسبه می‌شود (بدون داده: «داده‌ی کافی نیست»).

## پر کردن محتوا (همه‌چیز خالی شروع می‌شود)

- هیچ آگهی، مشاور، مقاله یا آمار نمایشی وجود ندارد. مجله هم خالی است و از پنل مدیریت ← «مجله» نوشته می‌شود (مقاله‌های آموزشی آماده‌ی `server/articles.js` فقط با `DAL_SEED_ARTICLES=1` وارد می‌شوند).
- همکاران: پنل مدیریت ← «کاربران و مشاوران» ← «افزودن همکار / مشاور». رمز موقت یک‌بار نشان داده می‌شود؛ آگهی مشاور تأییدشده مستقیم منتشر می‌شود و آگهی بقیه در صف تأیید می‌ماند.
- ثبت آگهی: دکمه‌ی «ثبت آگهی» (حداقل یک عکس لازم است).

## سرویس‌های رایگان

| سرویس | کاربرد | تنظیم |
|---|---|---|
| تلگرام Bot | هشدار فوری به مدیر (آگهی/پیام تازه) و **پشتیبان روزانه‌ی پایگاه‌داده** | توکن ربات از @BotFather + شناسه‌ی چت، در «تنظیمات» یا `DAL_TG_TOKEN` و `DAL_TG_CHAT` |
| OpenStreetMap Nominatim | جستجوی نشانی و پیدا کردن نشانی از روی نقشه هنگام ثبت آگهی | بدون کلید (رعایت سیاست استفاده‌ی منصفانه) |
| OpenStreetMap tiles + Leaflet | نقشه | بدون کلید |
| Caddy + Let's Encrypt | HTTPS خودکار | `Caddyfile` همراه پروژه |
| Oracle Cloud Always Free (یا هر VPS) | میزبانی | بخش «استقرار» |

> توکن تلگرام را می‌توانید در فایل `data/.env` هم بگذارید (دو خط: `DAL_TG_TOKEN=...` و `DAL_TG_CHAT=...`)؛ این فایل در git نمی‌رود.

> تلگرام، Nominatim و گواهی HTTPS به اینترنت وابسته‌اند و در محیط توسعه‌ی من آزمایش نشدند؛ منطق‌شان پیاده‌سازی شده و خطاها به‌صورت پیام فارسی نمایش داده می‌شوند.

## یک فایل

```bash
npm run bundle                 # ← release/dal.js  (سرور + فرانت + فونت + Leaflet، حدود ۱ مگابایت)
node release/dal.js            # فقط Node 22.13+ لازم است؛ داده‌ها در پوشه‌ی data کنار فایل
node release/dal.js admin 09123456789 "نام مدیر"   # دستورهای stats | backup | reset-password هم همین‌طور
```

## استقرار (Docker + HTTPS رایگان)

روی یک VM رایگان (مثلاً Oracle Always Free) با Docker:

```bash
git clone <repo> && cd <repo>
DOMAIN=your-domain.ir docker compose up -d     # بدون DOMAIN روی پورت ۸۰ بدون HTTPS بالا می‌آید
docker compose logs dal | grep "کد راه‌اندازی"   # سپس http(s)://دامنه/#/setup
```

داده‌ها در volume با نام `dal-data` می‌مانند. رکورد A دامنه را به IP سرور بدهید و پورت‌های ۸۰ و ۴۴۳ را باز کنید.

## اجرا در ایران و خارج از ایران 🇮🇷🌍

هدف: سایت **بدون فیلترشکن** در ایران کار کند و **با فیلترشکن** هم خوب باشد. دال این‌طور طراحی شده است:

- **هیچ منبع خارجی در مرورگر کاربر بارگذاری نمی‌شود.** فونت، Leaflet، آیکن‌ها و همه‌ی کدها از خود سایت می‌آیند. تنها وابستگی بیرونی نقشه بود که حالا از طریق **پروکسی کاشی روی همان سرور** (`/tiles/…`) و با **کش دیسکی** سرو می‌شود: مرورگر هرگز به OpenStreetMap وصل نمی‌شود، هر کاشی فقط یک‌بار از بالادست گرفته می‌شود (۳۰ روز تازه؛ اگر بالادست قطع بود نسخه‌ی قدیمی‌تر سرو می‌شود). حجم کش با `DAL_TILE_CACHE_MB` (پیش‌فرض ۴۰۰) محدود است.
- **اینترنت ضعیف:** فشرده‌سازی Brotli، مهلت و تکرار خودکار درخواست‌های خواندنی، نوار «اینترنت قطع است»، و Service Worker که آخرین آگهی‌ها/آمار و کاشی‌های دیده‌شده را بدون اینترنت نشان می‌دهد.
- **هشدار و پشتیبان با «بله» و تلگرام:** تلگرام در ایران فیلتر است، پس هشدار فوری و پشتیبان روزانه به هر پیام‌رسان تنظیم‌شده (بله و/یا تلگرام) هم‌زمان فرستاده می‌شود. پشتیبان **محلی** هم همیشه در `data/backups/` (هفت نسخه‌ی آخر) ساخته می‌شود و به اینترنت نیاز ندارد.
- **پنل «بررسی اتصال سرویس‌ها»** (مدیریت ← تنظیمات) نشان می‌دهد سرور شما به تلگرام، بله، سرور نقشه و جستجوی نشانی دسترسی دارد یا نه.

### میزبانی را کجا بگیریم؟

| گزینه | کاربر داخل ایران (بدون VPN) | کاربر خارج/با VPN | هشدار | نکته |
|---|---|---|---|---|
| **سرور داخل ایران** (ابرآروان، پارس‌پک، ایران‌سرور، …) ✅ پیشنهادی | سریع و پایدار | معمولاً خوب | **بله** | کاشی‌ها و نشانی‌یابی ممکن است از داخل به سرور خارجی نرسند؛ کش دیسکی و پیشنهاد بخش بعد کمک می‌کند. دامنه‌ی `.ir` و نماد اعتماد ممکن است لازم شود. |
| **سرور خارج از ایران** | ممکن است کند/ناپایدار باشد یا IP فیلتر شود | عالی | بله و تلگرام | برای کاربران ایرانی بدون VPN ریسک دارد؛ اگر بخش بزرگی از مخاطب در ایران است توصیه نمی‌شود. |
| **ترکیبی:** دال روی سرور داخل ایران + (اختیاری) رله‌ی تلگرام در خارج | سریع | خوب | بله + تلگرام از رله | بهترین حالت اگر تلگرام هم می‌خواهید: `DAL_TG_API=https://relay.example/` |

**جمع‌بندی پیشنهاد:** دال را روی یک VPS داخل ایران بگذارید و هشدار را به **بله** بفرستید. چون برنامه تک‌فایل و بدون وابستگی است، به Docker نیازی نیست (Docker Hub برای IPهای ایران مسدود است).

### نصب بدون Docker (پیشنهادی در ایران)

۱. `dal.js` را بسازید (`npm run bundle` → `release/dal.js`) یا فایل آماده را به سرور ببرید (`scp`).
۲. روی سرور (Ubuntu/Debian):

```bash
sudo bash deploy/install.sh ./dal.js
# اگر سرور به nodejs.org نمی‌رسد، فایل Node را خودتان ببرید:
sudo bash deploy/install.sh ./dal.js --node-tarball ./node-v22.14.0-linux-x64.tar.xz
```

اسکریپت Node ≥ 22.13 را (از چند آینه با جایگزین) در `/opt/dal/node` می‌گذارد، سرویس systemd می‌سازد (`deploy/dal.service`) و اجرا می‌کند. کد راه‌اندازی مدیر در `journalctl -u dal` و `/opt/dal/data/.setup-token` است. سپس `http://IP:3000/#/setup`.

**HTTPS:** nginx یا Caddy را جلوی پورت ۳۰۰۰ بگذارید و `TRUST_PROXY=1` را فعال کنید. گواهی رایگان Let's Encrypt از بعضی سرورهای ایران به‌سختی صادر می‌شود (ACME به خارج نیاز دارد)؛ در این حالت از گواهی داخلی/تجاری یا چالش DNS استفاده کنید. اگر Docker لازم شد: آینه‌ی رجیستری را در `/etc/docker/daemon.json` بگذارید (مثلاً `https://docker.arvancloud.ir` یا `https://registry.docker.ir`)؛ بسته‌های apt و npm هم آینه‌ی داخلی دارند (فهرست آینه‌ی لینوکس ابرآروان؛ `npm config set registry <آینه>`). دال خودش `npm install` لازم ندارد.

### ربات «بله» (پیشنهادی برای سرور داخل ایران)

۱) در بله به `@botfather` پیام بدهید، `/newbot` را بزنید و توکن را بگیرید. ۲) به ربات خودتان یک پیام بدهید. ۳) شناسه‌ی عددی گفتگوی خود را بگیرید. ۴) در «مدیریت ← تنظیمات ← ربات بله» توکن و شناسه را بگذارید و «ارسال پیام آزمایشی» را بزنید. یا در `data/.env`:

```
DAL_BALE_TOKEN=123456:ABC...
DAL_BALE_CHAT=123456789
```

برای تلگرام همان‌طور که قبلاً گفته شد (`DAL_TG_TOKEN`, `DAL_TG_CHAT`) و در صورت فیلتر بودن، نشانی رله در `DAL_TG_API`. شناسه‌ی «بله» و «ایتا» برای دکمه‌های تماس سایت هم در «تنظیمات» قابل ثبت است.

### متغیرهای مرتبط

| متغیر | کاربرد |
|---|---|
| `DAL_BALE_TOKEN`، `DAL_BALE_CHAT`، `DAL_BALE_API` | ربات بله (آدرس پایه‌ی پیش‌فرض `https://tapi.bale.ai`) |
| `DAL_TG_API` | رله‌ی تلگرام به‌جای `https://api.telegram.org` |
| `DAL_TILE_LIGHT`، `DAL_TILE_DARK` | الگوی آدرس کاشی بالادست (`{z}/{x}/{y}`)؛ می‌توانید به سرور کاشی داخلی/خودمیزبان اشاره دهید |
| `DAL_TILE_CACHE_MB` | سقف کش کاشی (پیش‌فرض ۴۰۰) |
| `TRUST_PROXY=1` | وقتی پشت nginx/Caddy هستید |

### صادقانه: چه چیزی را از اینجا نمی‌توان تست کرد

محیط توسعه‌ی من به اینترنت جهانی و به شبکه‌ی ایران دسترسی ندارد؛ پس **اتصال واقعی به Telegram/Bale/OSM/Nominatim از داخل ایران تست نشده است**. آنچه تست شده: پروکسی کاشی و کش (روی بالادست ساختگی)، ارسال هشدار با API سازگار با تلگرام/بله (روی سرور ساختگی)، پشتیبان محلی، عیب‌یابی، Brotli و بقیه‌ی برنامه (`npm test`). برای اطمینان نهایی بعد از استقرار، «بررسی اتصال سرویس‌ها» را در پنل مدیریت بزنید و سایت را یک‌بار با اینترنت همراه ایران و یک‌بار با VPN باز کنید.

## ورود و بازیابی رمز (بدون پیامک)

- ورود با **موبایل + رمز عبور** (حداقل ۸ نویسه، شامل حرف و عدد).
- هنگام ثبت‌نام یک **کد بازیابی** (`XXXX-XXXX-XXXX`) نمایش داده می‌شود که فقط یک‌بار دیده می‌شود. با آن در صفحه‌ی «فراموشی رمز» می‌توان رمز جدید گذاشت. کد را می‌توان از «پروفایل» دوباره ساخت.
- اگر کد هم گم شد: مدیر در پنل (کاربران ← آیکن کلید) رمز موقت می‌سازد، یا از ترمینال: `npm run reset-password -- 09123456789`.
- تغییر رمز یا مسدودسازی، همه‌ی نشست‌های قبلی را باطل می‌کند.
- پیامک/OTP در این نسخه وجود ندارد؛ برای افزودن آن به سرویس‌دهنده‌ی پیامک (مثلاً کاوه‌نگار، ملی‌پیامک) و کلید API نیاز است.

- علاقه‌مندی‌ها، بازدیدهای اخیر، مقایسه‌ی تا ۴ ملک (با رادار امتیاز محله)

**صفحه‌ی آگهی**
- گالری و نمایشگر تمام‌صفحه، مشخصات کامل، امکانات، نقشه و مسیریابی

- رزرو وقت بازدید، درخواست مشاوره، چت مستقیم با مشاور، نمایش شماره، گزارش تخلف، اشتراک‌گذاری، چاپ

**ابزارهای هوشمند**
- برآورد قیمت ملک (ترکیب «قیمت مرجع» محله و آگهی‌ها/معامله‌های مشابه ثبت‌شده در خود دال؛ مبنای هر برآورد در خروجی نمایش داده می‌شود)
- ماشین‌حساب وام مسکن، تبدیل رهن و اجاره، اجاره یا خرید، بازده سرمایه‌گذاری، توان خرید، کمیسیون
- تحلیل بازار: قیمت هر متر، روند و رشد (فقط از داده‌ی واقعی دال)، نقشه‌ی حرارتی محله‌ها

**جامعه و محتوا**
- مشاوران تأییدشده با پروفایل، امتیاز و نظرات
- تابلوی درخواست ملک (خریدار می‌نویسد، مشاوران پیشنهاد می‌دهند)

**حساب کاربری و مدیریت**
- داشبورد کاربر و مشاور: آگهی‌های من (آمار بازدید، CSV)، علاقه‌مندی‌ها، جستجوهای ذخیره‌شده، بازدیدها، درخواست‌ها، پیام‌ها

- پنل مدیریت: آمار، تأیید یا رد و حذف آگهی، ویژه‌کردن، کاربران و مشاوران (تأیید، مسدودسازی، رمز موقت، حذف)، گزارش‌ها، پیام‌های فرم تماس، مدیریت مقاله‌های مجله

## معماری

```
server/   Node http + node:sqlite  (index.js، db.js، services.js، valuation.js، nlp.js، seed.js …)
public/   SPA بدون فریم‌ورک (js/core.js، components.js، page-*.js، app.js) + css/app.css
data/     پایگاه‌داده و فایل‌های آپلودی (در git نیست)
```

- احراز هویت با توکن امضاشده (Bearer)، رمزها با scrypt
- فونت وزیرمتن و Leaflet به‌صورت محلی همراه پروژه‌اند؛ تنها کاشی‌های نقشه به اینترنت نیاز دارند
- آپلود تصویر با بررسی امضای فایل (JPEG/PNG/WebP)؛ هر آگهی حداقل یک تصویر دارد و فایل‌ها در `data/uploads` ذخیره می‌شوند
- مبلغ‌ها به تومان‌اند؛ در آگهی‌های رهن و اجاره، `price` ودیعه و `rent` اجاره‌ی ماهانه است

## اجرا در محیط واقعی

| متغیر | کاربرد |
|---|---|
| `PORT` | پورت (پیش‌فرض ۳۰۰۰) |
| `DAL_DATA_DIR`، `DAL_DB` | پوشه‌ی داده و مسیر پایگاه‌داده (پیش‌فرض `data/`) |
| `DAL_SECRET` | کلید امضای توکن؛ اگر نباشد در `data/.secret` ساخته می‌شود |
| `TRUST_PROXY=1` | پشت Nginx/Cloudflare برای خواندن IP واقعی از `X-Forwarded-For` (برای محدودسازی نرخ) |
| `DAL_ADMIN_PHONE`، `DAL_ADMIN_PASSWORD`، `DAL_ADMIN_NAME` | ساخت خودکار مدیر در اولین اجرا |
| `DAL_EXPIRE_DAYS` | عمر آگهی تا انقضا (پیش‌فرض ۹۰) |
| `DAL_TG_TOKEN`، `DAL_TG_CHAT` | ربات تلگرام برای هشدار و پشتیبان روزانه |
| `DAL_BALE_TOKEN`، `DAL_BALE_CHAT` | ربات بله (کار در ایران بدون فیلترشکن) — جزئیات در بخش «اجرا در ایران» |

- **پشتیبان‌گیری:** `npm run backup` (کپی سازگار از پایگاه‌داده با `VACUUM INTO`)؛ پوشه‌ی `data/uploads` را هم نگه دارید.
- **آمار:** `npm run stats`  ·  **تست:** `npm test` (روی پایگاه‌داده‌ی موقت)
- برای HTTPS و دامنه، یک reverse proxy (Nginx/Caddy) جلوی برنامه بگذارید.
- `npm run seed:demo` فقط برای توسعه است (داده‌ی نمایشی می‌ریزد) و جدا از اجرای عادی است.

## موارد وابسته به سرویس بیرونی (صادقانه)

- **کاشی‌های نقشه** از OpenStreetMap بارگذاری می‌شوند؛ برای ترافیک بالا سرویس کاشی اختصاصی بگیرید.
- **پیامک / پرداخت آنلاین:** پیاده‌سازی نشده‌اند (نیازمند حساب و کلید سرویس‌دهنده).
- **قیمت مرجع و امتیاز محله‌ها** فقط برای بخشی از محله‌های تهران و شیراز برآوردهای عمومی ثابت‌اند (در `server/meta.js`) و برای کنگان وجود ندارند، نه داده‌ی زنده. هرچه آگهی/معامله‌ی واقعی بیشتری ثبت شود، قیمت و روند بازار از داده‌ی واقعی دال محاسبه می‌شود و مبنای هر عدد (مرجع/بازار/ترکیبی) در رابط نمایش داده می‌شود.
- **تأیید پروانه‌ی مشاور** دستی است: مدیر شماره‌ی پروانه را بررسی و «تأیید» می‌کند.
