Dal on Windows - 3 steps
1) Install Node.js LTS from https://nodejs.org (Next, Next, Finish).
2) Double-click Start-Dal.bat  (keep the black window open).
3) First time only: double-click Setup-Code.bat, copy the code, then in the browser open
   http://localhost:3000/#/setup and fill in the form.
Backup: double-click Backup-Dal.bat, then copy the "data" folder somewhere safe.
